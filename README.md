# File Organizer

Python 文件整理工具第一版。仅依赖标准库，需要 Python 3.11 或更新版本。

## 功能

- 仅处理目标文件夹第一层普通文件，跳过子文件夹和符号链接。
- 按最后一个扩展名分类，不区分扩展名大小写：`photo.JPG` → `ext_jpg/photo.JPG`。
- 无扩展名及特殊扩展名放入 `no_extension`；`.tar.gz` 按 `gz` 分类。
- 默认仅预览，不创建目录、不移动文件；只有 `--apply` 才实际操作。
- 重名自动添加 ` (1)`、` (2)` 等编号，禁止覆盖已有文件。
- 每次实际整理生成独立 JSONL 日志，支持预览撤销与实际撤销。

## 使用方法

在终端进入本仓库目录。以下目标路径请替换为你要整理的文件夹：

```powershell
# 预览
python organizer.py "D:\Downloads\待整理"

# 实际整理
python organizer.py "D:\Downloads\待整理" --apply

# 将日志路径替换成整理命令输出的实际路径：先预览撤销
python organizer.py --undo "D:\Downloads\待整理\.file-organizer-logs\实际日志名.jsonl"

# 确认后执行撤销
python organizer.py --undo "D:\Downloads\待整理\.file-organizer-logs\实际日志名.jsonl" --apply
```

## 撤销与边界

日志保存在目标文件夹内 `.file-organizer-logs`。请保留日志，不要移动整个目标文件夹；多次整理请按操作的相反顺序撤销。

撤销只恢复文件，不删除分类目录或日志。原位置已存在文件、整理后的文件缺失或内容被修改时，会提示并跳过。重复撤销不会覆盖文件。

移动使用同一文件系统内的硬链接加删除原名称，创建目标时不会覆盖；需要文件系统支持硬链接（例如 NTFS），不支持时命令报错并保留源文件。操作中途出错可能已有部分文件完成移动，可使用输出的日志撤销。日志在每次移动前写入并落盘。

请先在副本上试用，整理期间避免其他程序同时修改目标文件。不要直接对本仓库运行整理，否则第一层源码也会按扩展名移动。
